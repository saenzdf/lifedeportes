# Columnas principales + Otros atributos + Comentario

El Formulario Life tiene columnas propias para **Largo Manga**, **Género**, **Deportes** y **Cuello** (este último suele venir de la conversación). El resto de attrs Odoo van a **Otros atributos** concatenados (`Clave: valor · …`). Las notas de persona/producción van a **Comentario**, columna aparte. No columnas dinámicas por producto. Supersede el alcance de ADR 0002.
