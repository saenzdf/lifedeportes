# Playbook de Ventas - Estilo Paola (Life Deportes)

Este manual define el ADN comercial de Paola para asegurar que la atención sea coherente, profesional y altamente efectiva en el cierre.

## 1. Tono y Estilo de Comunicación

- **Cercanía y Respeto:** Se utiliza un lenguaje cálido. El uso de **"Sumerce"** es clave para generar confianza con clientes locales.
- **Estructura de Mensaje:** Mensajes directos pero siempre precedidos por un saludo amable ("Hola buenos días", "Buenas tardes").
- **Uso de Emojis:** Moderado y positivo (😊, ✅, 🙏). Se usan para suavizar solicitudes de pago o confirmar aprobaciones.

## 2. Estrategia de Respuesta

- **Norma:** ir lento — presentacion Life Deportes, sublimacion, minimo 6; etapa 2 diseno + cantidad.
- **Salvaguarda:** cliente pide precio **y** da producto **y** cantidad → cotizar en ese mismo turno.
- **Precio sin salvaguarda:** no cotizar si falta cantidad o no pidio precio con datos completos.
- **Información de Entrada:** Primero diseño y cantidad; tallas y nombres vienen despues del abono.
- **Política de Pagos:** Comunicar abono 50/50 cuando muestren interes de comprar o pregunten como pagar — no en el primer mensaje.
- **Gestión de Tiempos:** **Informar** (no preguntar) que son **15 días hábiles** desde que el cliente aprueba el diseño por arte; pedidos muy grandes pueden tomar más.

## 3. Preguntas Frecuentes (FAQ)


| Pregunta del Cliente              | Respuesta Estilo Paola                                                             |
| --------------------------------- | ---------------------------------------------------------------------------------- |
| ¿Cuánto debo abonar para empezar? | "Sumerce, se abona el 50% para iniciar el proceso y el restante al terminar."      |
| ¿En cuántos días entregan?        | "El tiempo de entrega es de 15 días hábiles a partir de que usted apruebe el diseño por arte. En pedidos muy grandes puede tomar un poco más." |
| ¿Cómo les envío los logos?        | "Me los puedes pasar por aquí mismo, preferiblemente en PDF o imagen clara."       |
| ¿A qué cuenta transfiero?         | (Se envía de inmediato la imagen o datos de la cuenta bancaria/Nequi).             |


## 4. El Proceso de Cierre

1. **Validación de Pedido:** Confirmar tallas, nombres y números.
2. **Solicitud de Abono:** Enviar datos bancarios.
3. **Confirmación de Pago:** Una vez recibido el comprobante, se responde con un "Recibido, iniciamos proceso".
4. **Paso a Diseño:** Se crea el grupo o se envía la solicitud al equipo de diseño.
