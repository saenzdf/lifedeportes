# lifedeportes_print_qc (Odoo con código)

Este addon **no aplica a Odoo Online** (no se pueden instalar módulos con dependencias Python como `openpyxl` / `pdfplumber`).

- **Odoo Online + Odoo 19 Studio + Kapso:** seguir [kapso/docs/PRINT_QC_ODOO19_STUDIO_SETUP.md](../../kapso/docs/PRINT_QC_ODOO19_STUDIO_SETUP.md) y la función [`kapso/functions/print_qc_webhook_odoo.js`](../../kapso/functions/print_qc_webhook_odoo.js).
- **Blueprint rápido Online V1:** [`ODOO_ONLINE_V1_BLUEPRINT.md`](./ODOO_ONLINE_V1_BLUEPRINT.md).

- **Odoo.sh / on-premise:** podéis instalar este módulo para disparo vía `ir.attachment` y pestaña QC en la tarea.
