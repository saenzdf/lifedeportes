# Resumen de Cierre de Ventas

El éxito del cierre en Life Deportes depende de la transición fluida de la cotización al compromiso económico.

## Pasos Críticos para el Cierre

1. **Consolidación del Pedido:** Antes de pedir el pago, Paola resume el pedido (ej: "Pantalones de arquero T/10=2 T/12=5..."). Esto evita errores y muestra orden.
2. **El Trigger del 50%:** Se establece el abono como el único disparador para que el equipo de diseño eche a andar. "Sin abono no hay diseño" es la regla implícita.
3. **Facilidad de Pago:** Se envían los datos de transferencia de forma visual o texto copiable para que el cliente no tenga fricciones.
4. **Agradecimiento y Reafirmación:** Al recibir el pago, se usa un sticker o mensaje de "Con gusto" para confirmar que el cliente ahora es una prioridad en la cola de producción.

## Indicadores de Cierre Exitoso

- El cliente envía el comprobante de transferencia (Nequi/Bancolombia).
- El cliente envía el formato de pedido con el modelo de camiseta o logos.
